# Plugins and extensions
Plugins/extensions add new abilities to a host app by running installed code (new commands, UI, tool access, integrations). Example: Cline is a VS Code extension that adds an autonomous coding agent inside the editor.
Difference from skills: a skill is just packaged instructions that teach the model how to do a task better, while a plugin/extension is software that gives the host new capabilities. Extensions are host-specific and need more trust; skills are portable and lower risk.
